# Michael Havrylyuk — Engineering Portfolio

A responsive, dependency-free portfolio highlighting mechanical design, robotics, fabrication, and materials research projects.

## Local preview

Open `index.html` directly, or run a local static server:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

- `index.html` — accessible, semantic portfolio content
- `styles.css` — responsive editorial layout and visual system
- `script.js` — navigation, reveal effects, and image lightbox
- `assets/images/` — optimized WebP images extracted from the source portfolio
- `Michael Havrylyuk Portfolio.pdf` — original portfolio document
